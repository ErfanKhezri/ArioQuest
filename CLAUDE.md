  # ArioQuest
  Windows API client — React + TypeScript frontend, Tauri (Rust) backend.
  - Frontend: src/   Backend: src-tauri/
  - Install: npm install
  - Checks: npm run lint && npx tsc --noEmit && npm test
  - Rust: cd src-tauri && cargo check
  - Always run checks before finishing. Work on a new branch.
